Medical XAI

January 2026Python, scikit-learn, Flask, React

Ranks 16 conditions from free-text symptoms. Each score is split into text similarity (60%) and symptom overlap (40%), so a reader can see why one condition outranks another.

  1. Pick an example or tap symptoms.
  2. Open How this score was built under a result.
  3. Try the vague example to see the low-confidence message.

      Research demo, not medical advice. The scoring code in this page is a port of the project's Python model, and it returned identical rankings and scores on all 65 reference cases I compared.

      How well does it recover the right condition?

      There is no labelled clinical dataset in the repository, so these cases are simulated from the knowledge base itself: pick symptoms from a condition, optionally swap in synonyms or add unrelated symptoms, then check the ranking. This measures consistency, not diagnostic accuracy. Reproduce with python benchmark.py.

      Checked while preparing this page

      • The right condition lands in the top 3 in 96 to 100% of simulated cases, and first in 75 to 99%, depending on how noisy the input is. The hardest case is synonyms plus an unrelated symptom.
      • Inference takes 7 to 26 ms per query in Python (95th percentile under 35 ms), inside the 100 ms target.

        Autonomous Engineering Harness
        
            
        September 2026Python, OpenRouter, Pydantic, Typer
        
            
        A coding pipeline built to avoid runaway agent loops. Four model roles plan, write, run and review changes. A deterministic validator, not a model, decides whether a diff is valid, and fixed budgets decide when to stop.
        
          
        
          
        1. Pick a scenario.
        2. Press Step and watch which role acts and how the budgets change.
        3. Compare "Clean pass" with "Block, one re-plan, halt".
        
          
        
            
        Replay a run
        
            
        
            
          
            
          Reviewer PATCH sends one task back to the worker (limit 2). BLOCK sends the plan back to the architect (limit 1). Anything beyond a limit halts the run.
          
            
          
            
            
            
            
              
              
              
            
            
            
            
          
            
          
            
            
            What I tested and fixed
            
            
              
              
            • These replays are real traces from the orchestrator, driven by scripted model replies so no API key or network is needed. Ten pytest tests cover pass, patch, invalid diff, block and each budget halt.
              • 
              
            • Fixed: a rejected diff was counted but never retried, and exhausting the patch budget raised an exception instead of halting with saved evidence. Each run now also writes a trace.jsonl audit trail.
              • 
              
            • Fixed: pip install -e . failed on a packaging error. It installs now.
              • 
              
            • Not tested here: real model calls. Command safety is a deny-list, so it should run in a sandbox before use on important repositories.

              • I ran the agent on its sample model with no LLM key. Import analysis uses Python's own parser, and the scaffold comes from templates, so it works offline.
